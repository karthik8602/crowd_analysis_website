Computer Vision · Early-stage Project

Understanding crowd activity through video.

An AI-assisted video analytics project exploring person detection, movement analysis, and video-based violence classification to support crowd monitoring research.

Explore source code Technology stack

Project focus

01 · Person Detection

Explore computer vision techniques for identifying people in video frames.

02 · Video Classification

Develop temporal action-recognition methods to investigate fight and non-fight activity in video sequences.

03 · Monitoring Interface

Build a dashboard to present video-analysis results and support review of potential incidents.

Technology

Python OpenCV YOLO PyTorch CNN-LSTM Streamlit

Development roadmap

This project is under development. Planned work includes improving video classification, validating model performance, and exploring LLM-assisted incident summaries. Planned features are not yet presented as completed integrations.
